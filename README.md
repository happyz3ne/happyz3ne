## About me

```java
public final class MrZ3NE implements Developer {
    String project   = "Falatia — a Ukrainian Minecraft server";
    String[] crafts  = { "client mods", "server plugins", "backends", "3D models" };
    String  favorite = "making the vanilla game feel like a new one";
    String  motto    = "if it can be drawn, it can be rendered";
}
```

- I build **everything around a Minecraft server**: the client mod, the server plugins, and the backend that ties them together
- Recently: a **hand-drawn atlas** for Minecraft: a watercolor minimap, regions that reveal themselves, and recipe pages with 3D item previews in custom shaders
- A **3D main menu running on embedded Chromium** inside the game, with its own scene editor
- Backends in **Rust** (tokio, sqlx, serenity) and **Python** (asyncio, discord.py)
- Models in **Blockbench** and **Blender**, textures by hand
- Ask me about: Fabric mixins, Paper plugin messaging, render pipelines, Discord bots

## Falatia projects

| Project | What it does |
|---|---|
| **falatia-essentials** | Fabric client mod: Chromium 3D menu, atlas & minimap, cosmetics on the player model, photo mode, Discord Rich Presence, baked furniture rendering |
| **falatia-bridge** | Paper plugin syncing the mod with the server: shared atlas regions, Terra biome colors, CraftEngine recipes |
| **falatiamobs** | Custom mobs built on BetterModel and CraftEngine |
| **pigeonsplugin** | Pigeon mail: a real bird flies your parcel to a friend |
| **falatiacollection** | Crafting-collector stations with animated models |
| **falatia-magicdust** | A storage-block inspector that runs on magic dust |
| **falatiachat** | Chat formatting with HEX colors, LuckPerms and private messages |
| **falatiaauth** | Discord-linked authentication backed by PostgreSQL |
| **modserver-rust** | Async backend: WebSockets, Postgres, Discord bot, image processing |
